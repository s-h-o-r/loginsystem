# Singin and singup system
Простая система входа и регистрации. Однопоточное приложение командной строки, которое умеет регистрировать и сохранять данные. На данный момент MVP версией является простое осуществление регистрации, входа и смены данных пользователя с помощью командной строки. Данные не сериализуются и не сохраняются в БД. Также пароль и логин сохраняется в неизменном виде (на данный момент нет функции шифрования). Проект создан в учебных целях и будет развиваться до полноценного используемого приложения. В коде часто используются проектирования и попытка собрать системы с полноценным использование SOLID и TDD подхода. В том числе на реальном примере хочется понять, на сколько действительно проще создавать программы с использованием ООП и подобных подходов.

## Будущее проекта
На данный момент есть следующие идеи по развитию системы после подготовки MVP:
1. Повышение безопасности с использованием системы шифрования.
2. Логирование входа и выхода пользователей в отдельный файл.
3. Создание графического простого графического интерфейса с использованием фреймворка Qt.
4. Подключение асинхронной обработки операций и многопоточности.
5. Сериализация данных или подключение БД для сохранения паролей.
